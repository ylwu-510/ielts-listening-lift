# IELTS Listening Lift

**Turn a listening transcript into English you can say and write.**

[中文](README.md) · English

Give Codex an IELTS Listening transcript and get a clearly formatted **English–Chinese morning-reading handout**. Build up speaking expressions, useful collocations and sentence patterns, then practise them in complete responses. Works with Parts 1–4 or a single Part.

## Ask Codex to install it

Copy the following request and send it to Codex:

> Please use `$skill-installer` to install the `ielts-listening-lift` skill from this repository: https://github.com/ylwu-510/ielts-listening-lift

Once installed, you can start using it. If the skill does not appear, reopen Codex.

## Share a transcript, get a handout

Paste or attach your transcript in Codex and say:

> Use `$ielts-listening-lift` to turn this Cambridge IELTS 16 Test3 listening transcript into a bilingual morning-reading handout. Generate a Word document.

Change the test name for your next transcript. **Word is the preferred output.** For Markdown, just say “Generate Markdown this time.” Codex handles the selection, bilingual examples and document layout.

Want to try it before preparing a transcript? Use the included example:

> Use `$ielts-listening-lift` to generate a Word morning-reading handout from the skill’s included C16 Test2 example.

## What you get

| Section | Contents |
| --- | --- |
| **Speaking expressions** | Reusable phrases, Chinese meanings, natural examples and translations |
| **Reading and writing collocations** | Useful word combinations and ways to use them in other topics |
| **Sentence patterns** | Adaptable structures, examples and usage tips |
| **Complete responses** | Connected speaking answers or writing paragraphs, with Chinese translations |
| **Usage notes** | Pattern guidance, easily misread expressions and collocation boundaries |

Each section starts at **1.** The number of items and patterns depends on the transcript: richer material can yield more entries, with no fixed quota of eight patterns.

Key English phrases stand out, with Chinese directly below. Read aloud, then cover the English and try expressing the idea yourself. Adapted examples are distinguished from source wording so you can see how to reuse an expression.

## Make it fit your routine

Just continue the conversation with Codex:

- **Change format:** “Generate Markdown this time, keeping all the content.”
- **Adjust layout:** “It looks a little long. Tighten spacing and improve page breaks without removing learning material.”
- **Plan a session:** “Arrange the reading and recall practice into a 20–30-minute session.”
- **Adjust difficulty:** “Skip overly basic patterns and focus on expressions I can use in speaking and writing.”

**New transcript, same familiar format.** Use the same request whenever you finish another listening test.
