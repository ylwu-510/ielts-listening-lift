# IELTS Listening Lift

**把听力原稿，变成能读、能说、能写的英语。**

中文 · [English](README.en.md)

给 Codex 一份雅思听力稿，就能得到排版清晰的**中英对照早读材料**：提炼口语表达、读写搭配和句式，再用完整段落练习输出。支持 Part 1–4，也可以只整理其中一个 Part。

![早读 Word 示例：英文重点以青绿色加粗，中文译文紧随其后，编号与正文紧凑对齐](assets/readme/word-preview.png)

[C16 Test2 · 查看 Markdown 示例](examples/c16-test2.md) · [下载 Word 示例](examples/c16-test2.docx)

## 让 Codex 安装

直接复制下面这句话，发给 Codex：

> 请使用 `$skill-installer`，帮我安装这个仓库里的 `ielts-listening-lift` 技能：https://github.com/ylwu-510/ielts-listening-lift

安装完成后即可使用；如果技能没有显示，重新打开 Codex。

## 发原稿，拿到早读材料

在 Codex 中粘贴或附上听力稿，再说：

> 使用 `$ielts-listening-lift`，把这份剑雅 16 Test3 听力稿整理成早读材料，生成 Word 文档。

换一套题时，改一下题目名称即可。**默认优先生成 Word**；想要 Markdown，直接说“这次生成 MD”。内容提炼、中英例句和文档排版都由 Codex 完成。

还没有准备原稿，也可以先试试内置示例：

> 使用 `$ielts-listening-lift`，用技能自带的 C16 Test2 示例，给我生成一份 Word 早读材料。

## 你会得到什么

| 部分 | 内容 |
| --- | --- |
| **口语表达** | 常用表达、中文含义、自然例句及译文，方便开口练习 |
| **阅读和写作搭配** | 值得积累的搭配，以及在其他话题中的用法 |
| **句式** | 可迁移的句式骨架、例句与使用提示 |
| **完整的话** | 将表达串成连贯的口语回答或写作段落，中英对照 |
| **补充材料** | 新句式的使用重点、阅读中容易误解的表达、搭配的使用边界 |

每个部分独立从 **1.** 开始编号。条目和句式数量随原稿而定，有用的内容多，就多收录；不会每篇都硬凑成八组句式。

英文重点突出，中文紧随其后，适合先朗读、再遮住英文复述。迁移例句与原文表达会作区分，方便理解后用到自己的话题里。

## 按你的习惯调整

直接继续对 Codex 说就行：

- **换格式：**“这次生成 Markdown，内容保持完整。”
- **调排版：**“看起来有点长，收紧间距、优化分页，不要删学习内容。”
- **安排早读：**“按 20–30 分钟帮我安排朗读和复述顺序。”
- **调难度：**“少选过于基础的句式，多选能用在口语和写作里的表达。”

**内容跟着原稿走，排版沿用同一套。** 下一次换一份听力稿，仍然这样使用。
